# Unity 64×64 Pixel Character Production Specification

이 문서는 프로젝트의 64×64 캐릭터 제작 단일 기준으로 사용한다.

## 핵심 목표

원본 캐릭터의 정체성과 주요 디자인 요소를 유지하면서 실제 게임에서 사용할 수 있는 64×64 픽셀 아트로 재해석한다. 고해상도 이미지를 축소하지 않고 64×64 픽셀 그리드에서 직접 제작한다.

## 출력 규격

- 정확히 64×64 px인 PNG RGBA
- 투명 배경과 1×1 실제 픽셀 단위
- 안티앨리어싱, 블러, 부드러운 가장자리, 서브픽셀, 불필요한 반투명 픽셀 금지
- 1~2px 외곽선과 단계식 명암(Highlight → Base → Shadow)
- 일반적으로 8~20색의 제한된 팔레트
- 인간형 캐릭터 높이 약 44~58px
- 모든 프레임의 발 위치와 기준점 고정

## 디자인 우선순위

1. 핵심 실루엣
2. 얼굴과 헤어스타일
3. 대표 색상
4. 의상
5. 무기와 장비
6. 액세서리
7. 세부 장식

## 애니메이션 고정 요소

- 머리 크기와 얼굴 위치
- 몸통 크기와 신체 비율
- 캐릭터 전체 크기와 발 위치
- 무기 크기와 기준 위치
- 픽셀 밀도, 팔레트, 외곽선 스타일

## Unity Import 설정

- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Pixels Per Unit: 64
- Filter Mode: Point (no filter)
- Mip Maps: Off
- Compression: None 또는 무손실
- Pivot: Bottom Center
- Wrap Mode: Clamp

## 필수 검수

정확한 64×64 크기, 실제 픽셀 아트, 불투명 또는 완전 투명 픽셀, 일관된 픽셀 크기·팔레트·외곽선, 원본의 핵심 특징, 44~58px 높이, 고정된 발 기준선, 후속 애니메이션 확장성을 모두 만족해야 한다. 하나라도 만족하지 못하면 확정하지 않고 수정한다.
