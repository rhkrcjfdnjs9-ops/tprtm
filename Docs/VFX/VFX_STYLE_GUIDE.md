# VFX Style Guide

## 1. 시각 목표

작은 픽셀 캐릭터의 실루엣을 유지하면서, 공격의 위력과 속성은 더 높은 해상도의 에너지 표현으로 보강한다. 화려함보다 판독 순서를 우선한다.

```text
공격 방향 → 에너지 핵 → 타격 지점 → 작은 잔상
```

## 2. 실루엣 우선 설계

- 선과 파편을 그리기 전에 전체 외곽 형태를 먼저 확정한다.
- 큰 실루엣 1개, 중간 에너지 1~3개, 작은 파편 소수로 구성한다.
- 완전한 원, 완전 대칭, 동일 간격 방사형 선을 기본 형태로 사용하지 않는다.
- 프레임 수보다 시작, 최대 압축, 최대 타격, 종료 키프레임의 차이를 우선한다.

## 3. 번개 표현 규칙

- 단순 직선이나 균일한 polyline으로 표현하지 않는다.
- 시작점은 굵고 중간에는 불규칙한 굵기 변화가 있어야 한다.
- 끝은 좁고 날카롭게 마감한다.
- 꺾임 길이와 각도를 반복하지 않는다.
- 좌우 대칭, 평행 반복, 과도한 가지 수를 피한다.
- 주 번개 1~3개와 짧은 보조 방전으로 위계를 나눈다.
- 에너지 덩어리와 번개 파편을 시각적으로 구분한다.

## 4. 하이브리드 해상도

### Pixel Layer

- 접촉점, 핵심 플래시, 명확한 번개 끝, 상태 아이콘에 사용한다.
- Point Filter와 PPU 32를 따른다.
- 반투명 가장자리와 부드러운 축소를 사용하지 않는다.

### High Resolution Layer

- 플라스마 외곽, 연무, 잔광, 부드러운 왜곡에 사용한다.
- 캐릭터보다 뒤 또는 짧은 시간 동안만 앞에 표시한다.
- 캐릭터 픽셀 외곽을 흐리게 만들 정도의 Bloom을 금지한다.

## 5. 타이밍 기준

| 단계 | 권장 비중 | 역할 |
|---|---:|---|
| Anticipation | 20~30% | 힘이 모이는 방향을 보여준다. |
| Release | 10~20% | 가장 빠른 변화로 발사를 인식시킨다. |
| Travel | 20~35% | 발사체 방향과 속도를 전달한다. |
| Impact | 10~20% | 가장 밝고 큰 실루엣을 1~2 키프레임 유지한다. |
| Decay | 15~25% | 작은 파편과 잔광을 빠르게 제거한다. |

Hit Stop은 강한 스킬의 최대 타격 키프레임에만 사용하며 기본 범위는 0.03~0.08초다. Camera Shake는 감쇠하며 UI와 카메라 기준점을 영구 이동시키지 않는다.

## 6. 가독성 규칙

- 동일 팀의 캐릭터 얼굴을 0.15초 이상 완전히 가리지 않는다.
- 피격 대상의 위치를 최대 타격 프레임에서도 추적할 수 있어야 한다.
- 배경과 값(Value)이 겹치면 외곽선 또는 짧은 흰색 핵으로 분리한다.
- Damage Number, HP Bar 및 전투 UI보다 낮은 Sorting Layer를 사용한다.

## 7. 속성 형태 언어

- 물: 곡선, 낙하, 원호, 투명한 중간값
- 불: 상승, 찢어진 불꽃, 적색 중심과 황백색 최고광
- 바람: 열린 곡선, 얇은 절단면, 청록색 잔상
- 번개: 불규칙한 압축 덩어리, 굵기 변화, 날카로운 분기
- 빛: 정돈된 광선, 별 모양 핵, 따뜻한 백색
- 어둠: 비대칭 흡수 실루엣, 빈 중심, 자주색/남색 잔류물

속성 언어를 바꾸려면 `VFX_PALETTE.md`와 함께 승인받아 개정한다.

## 8. URP 2D / Shader Graph 규칙

- 기본 VFX Shader Graph Target은 `URP Sprite Unlit`으로 한다.
- 실제 2D Light의 영향을 받아야 하는 VFX만 `URP Sprite Lit`을 사용한다.
- Blend는 Alpha 또는 Additive 중 하나를 VFX Design Plan에 명시한다.
- HDR Color와 Bloom은 핵심 발광부에만 사용하고 캐릭터 얼굴과 실루엣을 덮지 않게 제한한다.
- 색상, 강도, 왜곡량, 소멸량은 Material Property로 노출하고 Prefab마다 Material을 임의 복제하지 않는다.
- 풀에서 재사용되는 VFX는 활성화할 때 Material Property와 애니메이션 시간을 초기화한다.
- 모바일 화면 전체를 덮는 Fullscreen Shader, 다중 패스, 과도한 노이즈 샘플링은 사용하지 않는다.
- 픽셀 핵심층에는 UV 왜곡, Bilinear 확대, 부드러운 알파 가장자리를 적용하지 않는다.
- 고해상도 보조층에만 플라스마, Dissolve, 왜곡, 부드러운 Glow를 허용한다.
- Shader Graph 추가 후 Android 세로 화면에서 캐릭터 가독성, Overdraw, 60 FPS를 다시 검증한다.
