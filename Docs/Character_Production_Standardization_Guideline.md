# 캐릭터 제작 표준화 지침

## 1. 기본 원칙

현재 완성된 **아르카(Arca)**의 제작 과정을 앞으로 제작되는 모든 2D 도트 픽셀 캐릭터의 **기준 제작 방식(Template)**으로 사용한다.

아르카를 다시 제작하라는 의미가 아니다.

아르카 제작 과정에서 이미 확정된 다음 요소들을 추출하여 **재사용 가능한 제작 규칙**으로 만들고, 이후 새로운 캐릭터 제작 시 동일한 규칙과 작업 순서를 적용한다.

## 2. 절대 다시 만들지 않는 것

이미 아르카 제작 과정에서 확정된 공통 규칙은 새로운 캐릭터마다 다시 결정하지 않는다.

- 캔버스 규격
- 픽셀 해상도
- PPU
- 캐릭터 기준 크기
- 캐릭터 배치 기준
- 발 위치 기준선
- 중심축
- 픽셀 아트 스타일
- 외곽선 규칙
- 색상 사용 규칙
- 명암 표현 방식
- 투명 배경 규칙
- 파일 포맷
- 파일명 규칙
- 폴더 구조
- 애니메이션 제작 규칙
- Unity import 설정
- Sprite 설정
- Animator 구성 방식

위와 같은 **공통 제작 규칙은 아르카에서 확정된 기준을 그대로 재사용한다.**

## 3. 새로운 캐릭터에서 변경할 수 있는 것

새로운 캐릭터마다 다음과 같은 개별 요소만 변경한다.

- 캐릭터 이름
- 성별
- 헤어스타일
- 얼굴
- 의상
- 무기
- 장식
- 속성
- 색상
- 체형
- 캐릭터 개성
- 전투 스타일
- 필요한 애니메이션

즉, **제작 시스템은 동일하게 유지하고 캐릭터의 내용만 변경한다.**

## 4. 새로운 캐릭터 제작 절차

새 캐릭터를 제작할 때는 다음 순서를 따른다.

1. 기존 캐릭터 제작 표준을 불러온다.
2. 아르카에서 확정된 공통 규칙을 그대로 적용한다.
3. 새로운 캐릭터의 개별 디자인 정보를 입력한다.
4. 공통 규격에 맞춰 원본 캐릭터를 제작한다.
5. 기존 캐릭터와 동일한 기준으로 픽셀 캐릭터를 제작한다.
6. 기존 캐릭터와 동일한 애니메이션 제작 방식을 적용한다.
7. 동일한 Unity 규격으로 Export한다.
8. 기존 캐릭터와 동일한 Unity Import 규칙을 적용한다.
9. 최종 결과가 기존 캐릭터와 동일한 제작 규격을 따르는지 검증한다.

## 5. 중요한 원칙

새로운 캐릭터를 제작할 때마다 제작 방식을 새로 설계하지 않는다.

**"아르카를 어떻게 만들었는가?"를 기준으로 새로운 캐릭터를 제작한다.**

다만 새로운 캐릭터 제작 과정에서 기존 규칙으로 해결할 수 없는 문제가 발견될 경우 다음 절차를 따른다.

1. 기존 규칙을 임의로 변경하지 않는다.
2. 문제가 기존 캐릭터에도 영향을 주는지 확인한다.
3. 공통 규칙으로 승격할 가치가 있는 경우 제작 표준을 업데이트한다.
4. 이후 제작되는 모든 캐릭터에 업데이트된 규칙을 적용한다.

## 6. 목표

최종적으로 새로운 캐릭터를 추가할 때마다 **처음부터 새로 제작**하는 것이 아니라, **기존 캐릭터 제작 템플릿을 복제하고 캐릭터별 내용만 교체**하는 방식으로 제작한다.

아르카는 첫 번째 완성 캐릭터이며 동시에 전체 캐릭터 제작 시스템의 **Reference Character(기준 캐릭터)**로 취급한다.
